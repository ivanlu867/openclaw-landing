OpenClaw 安装完整教程
Windows / Mac 从零到可用

📅 2026年3月20日 📍 墨尔本
Mac 用户：直接在终端安装即可，不需要额外配置环境。
1

安装 OpenClaw

打开终端（Terminal），运行以下命令：

sudo curl -fsSL https://openclaw.ai/install.sh | bash
注意：输入密码时屏幕不会显示任何字符，这是正常的安全机制。直接输入后按 Enter 即可。
如果提示安装 Xcode Command Line Tools，按提示安装后继续。
2

完成 Onboarding 配置

① 选择 QuickStart
第一次使用选 QuickStart。

② 选择 Provider：OpenAI
选 OpenAI (Codex OAuth + API key)。

③ OpenAI 登录授权

  • 复制终端显示的 URL，粘贴到浏览器
  • 用 ChatGPT / OpenAI 账号登录并授权
  • 回到终端继续

④ 默认模型
保持默认即可，之后随时可以更改。

⑤ 配置 Telegram Bot

  1. 打开 Telegram，搜索 @BotFather（官方机器人管理账号）
  2. 发送命令 /newbot
  3. 设置 Bot 用户名（必须以 bot 结尾，例如 myopenclaw_bot）
  4. 复制生成的 Token，粘贴回 OpenClaw 终端
提示：选项用空格键选中，Enter 键确认。

⑥ 安装 Skills 依赖
按提示继续安装缺少的依赖。暂时不需要的 Skill 可以跳过。

Windows 用户：需要先安装 WSL + Ubuntu 24.04，然后在 Ubuntu 内安装 OpenClaw。
1

检查虚拟化是否开启

按 Ctrl + Shift + Esc 打开任务管理器 → 性能 → CPU → 查看「虚拟化：已启用」。

如果显示「已禁用」，需要进入 BIOS/UEFI 开启虚拟化后再继续。

2

安装 Ubuntu 24.04（WSL）

用管理员权限打开 PowerShell，依次运行：

wsl --install -d Ubuntu-24.04

如需重启：

shutdown /r /t 0

重启后验证安装：

wsl --list --verbose

设置默认版本：

wsl --set-default-version 2
wsl --set-default Ubuntu-24.04

进入 Ubuntu（首次会提示设置 Linux 用户名和密码，记住这个密码）：

wsl -d Ubuntu-24.04
3

在 Ubuntu 内安装 OpenClaw

进入 Ubuntu 终端后，运行：

sudo curl -fsSL https://openclaw.ai/install.sh | bash
注意：输入密码时屏幕不会显示任何字符，这是正常的。直接输入 WSL Ubuntu 密码后按 Enter。
4

完成 Onboarding 配置

步骤与 Mac 完全一致：QuickStart → OpenAI 授权 → 配置 Telegram Bot → 安装依赖。

详细步骤见 Mac 教程第 2 步。

✦

Workspace 文件配置（重要）

OpenClaw 能否稳定运行，很大程度取决于 Workspace .md 文件是否整理到位，而不是对话频率。

推荐目录结构：

workspace/
  ├── AGENTS.md    ← 执行规则
  ├── SOUL.md      ← 个性与原则
  ├── IDENTITY.md  ← Agent 元数据
  ├── USER.md      ← 用户信息
  ├── TOOLS.md     ← 本地环境配置
  ├── HEARTBEAT.md ← 定期维护清单
  ├── MEMORY.md    ← 长期记忆偏好
  └── memory/
        └── 2026-03-20.md

常驻注入文件（每次会话都加载）：

文件 用途 建议
AGENTS.md 执行规则、安全边界、消息规范 引用其他文件，不重复内容
SOUL.md 个性、原则、边界 哲学性，简洁；定义「是谁」不是「做什么」
IDENTITY.md 名字、类型、emoji、头像 5-10 行，纯事实
USER.md 用户姓名、时区、邮箱、偏好 只放个人信息
TOOLS.md 本地配置：频道 ID、token、路径 环境配置笔记，不是文档
HEARTBEAT.md 每 30 分钟心跳检查 保持极简
Token 成本提示：常驻注入文件总字符建议控制在 20,000 以内。每行都有 token 成本，保持文件精简。
