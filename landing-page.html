Level 1 · Chat

我问，AI 回答：写作、总结、分析和建议。

🤖

Level 2 · Agent

我给目标，AI 自己完成多个步骤并交付结果。

🧩

Level 3 · Skill

把你的经验、标准和方法教给 AI，让能力可以重复使用。

📚

Level 4 · 知识库

让 AI 使用你的文件、资料、SOP 和公司知识。

⚡

Level 5 · Workflow

把一套做事方法变成以后都能重复执行的流程。

课程内容

从会聊天，到让 AI 真正替你完成工作

不绑定一个工具，学习 Agent、Skill、知识库与 Workflow 的底层方法，并把它应用到自己的真实问题。

🧾

WorkBuddy：办公 Agent

读取文件、整理资料、做研究、分析数据，生成 Word、Excel、PPT 等可交付成果。

💰

Codex：处理文件与复杂任务

不是程序员，也能让 Codex 帮你处理文件夹、PDF、Excel 和项目，把多个步骤变成结果。

📧

Skill：把经验教给 AI

把你的判断标准、步骤和输出格式封装起来。Prompt 用一次，Skill 可以一直重复使用。

☀️

知识库：让 AI 懂你的资料

把产品资料、SOP、历史文件和专业知识交给 AI，回答不再只依赖互联网的通用知识。

📚

Workflow：让方法重复运行

客户需求 → 读取资料 → 调用 Skill → 分析计算 → 生成 PDF/Excel → 人工确认。

常见问题

你可能想问的

我完全不懂技术，能学会吗？
可以。过去课程已有72岁学员和大量非技术背景的老板、家庭主妇参加并完成实操。新版课程会把课堂时间更多用于真实任务，而不是现场排查安装问题。
Chat、Agent、Skill、知识库和 Workflow 有什么区别？
Chat 是你问、AI 回答；Agent 是你给目标、AI 执行多步骤任务；Skill 是把你的方法教给 AI；知识库让 AI 懂你的资料；Workflow 则把整套方法变成可以重复运行的流程。
安全吗？数据会泄露吗？
OpenClaw 安装在你自己的电脑上，数据存储在本地。课程会详细讲解如何设置安全边界、控制权限、降低风险。
课程一天学完能真的会用吗？
课程结束时，你至少带走一套 Agent 使用认知、一个自己的 Skill、一个知识库方向，以及一个可以继续迭代的 AI Workflow。OpenClaw 作为延伸路线介绍，安装不再占用全班核心时间。
